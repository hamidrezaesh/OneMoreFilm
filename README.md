<p align="center">
  <a href="https://onemorefilm.pages.dev/">Link</a>
</p>

<p align="center">A simple movie discovery website that randomly picks a movie for you.
</p>

## Features
- Random movie recommendations
- Movie posters and details
- IMDb links
- Powered by [Cinemeta API](https://bytetools.bytevancer.com/public-apis/video/cinemeta-api)

## Tech Stack
- React
- JavaScript
- Tailwind CSS
- Vite

## Run Locally

```bash
git clone https://github.com/hamidrezaesh/OneMoreFilm.git
cd OneMoreFilm
npm install
npm run dev
```
