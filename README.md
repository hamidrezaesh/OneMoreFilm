# [ One More Film 🎬](https://onemorefilm.pages.dev/)

A simple movie discovery website that randomly picks a movie for you.

## Features
- Random movie recommendations
- Movie posters and details
- IMDb links
- Powered by [Cinemeta API](https://bytetools.bytevancer.com/public-apis/video/cinemeta-api)

## Tech Stack
- React
- JavaScript
- Tailwind CSS
- Vite

## Run Locally

```bash
git clone https://github.com/hamidrezaesh/one-more-film.git
cd one-more-film
npm install
npm run dev
```
